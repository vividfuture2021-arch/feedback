# 校园意见箱微信小程序

这是一个基于微信云开发的学校意见收集小程序。当前云开发环境 ID 已配置为：

```text
cloud1-d3gqe9h1j8d185219
```

## 已实现

- 学生、教师、家长等身份提交意见
- 支持匿名、分类、紧急程度、地点、联系方式和是否需要回复
- 当前微信账号查看“我的反馈”和学校回复
- 管理端看板：搜索、筛选、查看详情、修改状态、保存回复
- 意见数据写入云数据库集合 `feedbacks`
- 管理密码通过云函数校验，不再写死在小程序前端

## 本地运行

1. 打开微信开发者工具。
2. 选择“导入项目”，目录选 `E:\意见收集`。
3. 确认 AppID 是当前项目的 AppID。
4. 编译后进入“提交意见”页面体验。

## 云开发部署

第一次使用需要在微信开发者工具里完成下面几步：

1. 打开“云开发”，确认选择环境 `cloud1-d3gqe9h1j8d185219`。
2. 进入“数据库”，创建集合 `feedbacks`。
3. 在左侧项目文件里找到 `cloudfunctions/feedback`。
4. 右键 `feedback` 文件夹，选择“上传并部署：云端安装依赖”。
5. 部署成功后重新编译小程序。

管理端入口在底部“处理看板”，管理密码在云函数环境变量中校验，不在小程序前台展示，也不写死在代码里。

使用前需要在云开发控制台给云函数 `feedback` 配置环境变量：

```text
ADMIN_PASSWORD=你的管理密码
```

配置后重新部署或重启云函数，再用这个密码登录管理端。

## 数据说明

- 意见数据保存在云数据库集合 `feedbacks`
- 每条意见会记录提交人的微信 OpenID，用于“我的反馈”
- 管理端通过云函数读取全部意见
- “我的反馈”里的删除只会在当前设备隐藏记录，不会删除云端后台记录
